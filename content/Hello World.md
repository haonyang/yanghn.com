# Hello World

This is my first post on the new blog. I rebuilt the whole thing from scratch using [Quartz](https://quartz.jzhao.xyz/) -- a static site generator designed for Obsidian vaults.

## Why Quartz?

I tried a bunch of tools before -- Hugo, Digital Garden, and the old Quartz v3. They all worked, but none of them felt *right*. What I really wanted was simple:

- Write markdown in Obsidian, just like I always do
- Drop the file into a folder
- It shows up on my website

That's it. No frontmatter gymnastics, no HTML, no build configs to fiddle with. Quartz v4 does exactly this.

## What you'll find here

I write about whatever I'm learning or thinking about:

- **Deep Learning** -- notes from courses, paper summaries, experiment logs
- **Programming** -- things I build, tools I use, problems I solve
- **Life** -- books, movies, cooking, and other things that make life interesting
